## Technical Constraints

- Backend must be implemented using Go.
- PostgreSQL is the primary database.
- Kafka is used as the message broker.
- Redis is used as the temporary cache.
- Docker Compose is used for deployment.

---

## Project Constraints

- The project is developed by a single developer.
- Development time is limited to approximately three months.
- The initial version targets a single-machine deployment.

---

## Scope Constraints

The first version does not include:

- Authentication
- Multi-tenancy
- Cloud deployment
- Kubernetes
- External payment providers
